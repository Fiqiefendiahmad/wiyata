# UX and Page Specification

## Brand

- Name: WIYATA
- Tagline: Your Database Learning Center
- Supporting line: Learn, build, explore, and master database technologies — all in one place.
- Identity: Indonesian cultural inspiration through the product name; interface language remains English or Bahasa Indonesia.
- Avoid using Indonesian/Javanese labels throughout the product solely for branding. Standard technical language is preferred.

## Visual direction

- Professional developer-tool aesthetic.
- Deep navy foundation with restrained gold accent inspired by the app icon.
- Neutral surfaces and readable contrast.
- Avoid decorative cultural motifs in every component; use subtle heritage details only in brand assets.
- Light and dark themes are desirable.
- Desktop-first workspace, responsive learning and reference pages.

## Dashboard

Show:
- Continue learning
- Recent sandboxes
- Recent queries
- Saved queries
- Favorite tools
- Recommended learning paths
- Platform status and notices

## Database Lab page

Show:
- Create environment
- Engine and version selector
- Empty or template database
- Expiration and quota
- Active environment cards
- Open SQL workspace
- Reset, export, snapshot, delete

## Query Studio

Four-pane desktop layout:
- Left: connection/schema explorer
- Center: Monaco SQL editor and tabs
- Right: assistant/explanation panel
- Bottom: results, messages, execution plan

Provide manual mode even when AI is unavailable.

## Knowledge Center

- Search-first landing page.
- General topics and database-specific collections.
- Filters by engine, version, level, and category.
- Article table of contents.
- Code examples with copy action.
- Linked sandbox exercises.
- References and last-reviewed date.
- Language switch.

## Professional Tools

- Search and filters by category, database engine, operating system, deployment model, license, and skill level.
- Tool cards must identify licensing clearly.
- Each tool has a detailed knowledge page.
- Provide alternatives and comparison pages.
- Show official website and documentation links.

## Professional Workflows

- Scenario description
- Prerequisites and risk level
- Tools needed
- Step-by-step procedure
- Verification
- Rollback/recovery
- Related articles
- Sandbox exercise where safe

## Learning Paths

- Role profile
- Skill matrix
- Prerequisites
- Ordered modules
- Exercises and assessments
- Progress tracking
- Suggested tools
- Practical capstone

## Database Workspace

- External connection management.
- Connection test.
- Schema explorer.
- Query execution with explicit confirmation.
- Monitoring/diagnostic features only when adapter capabilities and permissions allow.

## Accessibility

- Keyboard-first editor interactions.
- Visible focus states.
- WCAG-oriented contrast.
- Semantic headings and labels.
- Avoid color-only status communication.
- Responsive mobile reading; complex query workspace may be desktop-optimized.
