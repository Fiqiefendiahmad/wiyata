# Definition of Done

A feature is complete only when:
- Product behavior matches the approved requirement.
- English and Indonesian strings exist.
- Accessibility basics are addressed.
- API contracts and error handling are documented.
- Unit and relevant integration tests pass.
- Security implications are reviewed.
- Logging and metrics are adequate without exposing secrets.
- User-facing limitations are clear.
- Documentation is updated.
- Database migrations are reversible or have a documented recovery plan.
- No unsupported database capability is presented as available.
- Any external tool licensing and version claims are sourced and reviewed.
